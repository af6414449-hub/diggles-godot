# Реальное копание и независимые гномы — 2026-11-17

На multiplayer start 010 проверен цикл: разметка → назначение выбранному гному → подход → исходная анимация → принятый переход BlockDB → обновление мешей, коллизий и доступности. В этой итерации устранено общее состояние маршрута: второй гном больше не отменяет первого.

## Исходные правила и границы переноса

`native_terrain_state.gd` использует доказанное ядро `0x596B80` после отдельной объектной политики. Из четырёх старых ссылок снимком выбирается по одному `next[corner]`, а не цепочка; замена принимается только при совпадении высоты с общим Hnext. Проверки всех восьми nibble-слотов и dirty regions сохранены. UI пока отображает native slot 0 как owner/layer 0/0.

Пакет `multi_start_010_mutable.json` содержит 3105 достижимых блоков, исходные меши и 8×8 высотные профили. Экспортёр сверяет реальные PMP/BDB SHA-256 и все 238 первоначальных mesh-записей. Пакет теперь канонически записывается с LF: единственным расхождением первой проверки был старый CRLF после последней скобки; JSON-данные совпадали.

Контрольный удар (9,3) заменяет NW/NE/SW/SE `0/0/0/0 → 22/32/44/54`; corridor3 снимается в этой же операции. Physics ray в (9.01,3.01) до удара попадает в Z=15, после — в Z=11. Это замена настоящей поверхности, а не исчезновение зелёной метки. Дополнительные независимые fixtures покрывают частичную замену, повторный отказ, более глубокую цель и восемь packed slots: см. `native-terrain-strike-2026-11-17.md/.json`.

`z_dignwalk.tcl` подтверждает ground-позы, смещение worker `{0 -0.8 0}`, строгую досягаемость XY `<3+exp_Stein`, минимум два из трёх соседей `<13` и gameplay callback после завершения action. Для точки (2,15) гном подходит к (3,14.5,12) и играет исходный `buddeln_unten`, 13 кадров. Полный callback `dig_execute` оригинала может принять ноль или несколько операций; нынешний один принятый шаг и 12 FPS — явные адаптеры. Звуковое событие frame_raw=5 не используется как удар. Данные/доказательства: `dwarf-dig-action-2026-11-17.md`.

Выбор стойки и A* одного пола Y=14.5 остаются адаптерами. Native `get_digedge`, `vector_fixdig`, `dig_next`, многоуровневый action-walk и лазание ещё не интегрированы. Нет RNG/аварий/ресурсов/полной объектной политики. Кирка не прикрепляется через придуманный offset: исходный attachment transform руки пока не подтверждён. Шапки, речь, mixed Gnd/Msk и освещение в этом приращении не менялись.

## Независимость актёров

`floor_walk_action.gd` хранит путь, текущий узел, поворот/клип, elapsed/frame, fast-режим и цель-бочку отдельно для каждого гнома. История последней цели тоже индивидуальная. `moving_dwarf` и прежние поля остались только диагностической проекцией одного маршрута; исполнение обходится без переключения глобального контекста.

Отмена и завершение удаляют только действие своего актёра. В новом интеграционном примере сначала одновременно идут два гнома; второй получает другую цель и отмену, первый продолжает. Затем назначены (1,15) и (2,15), пока третий гном идёт в (16,14.5,14). Первый завершает свой удар, второй сохраняет задание и позже завершает свой; итог — два callback, две принятые мутации, обе метки удалены. Третий доходит независимо. Отдельно проверено прекращение пути перед ставшим solid следующим узлом, без шага в него.

Это ещё не перенос индивидуального AI или native обхода динамического мира: нет автоматического выбора следующей работы, смены высоты, взаимного обхода актёров и native retry-политики.
