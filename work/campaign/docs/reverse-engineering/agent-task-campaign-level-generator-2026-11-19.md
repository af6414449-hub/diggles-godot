# Задача агенту: генератор уровня кампании — сборка главы из оригинальных шаблонов

## Цель

В оригинале уровень — **не готовый файл, а процедурная сборка из шаблонов**.
Перенести эту процедуру в Godot-проект, чтобы уровень главы получался из
оригинальных шаблонов детерминированно по seed, а не вылизывался вручную.

Это разблокирует главы: без генератора каждый уровень — ручная работа, а
кампания состоит из процедурных уровней.

Подготовка (разбор оригинала, таблицы `first_level`, формат шаблона, инвентарь
874 файлов `urw_*`, что уже есть в проекте) сделана — см.
`MiniMax\Diggles\docs\plan\campaign-generator-2026-11-19.md`. Не переделывать
разбор, а взять контракт оттуда и проверить его по источнику.

Это исследование и подготовка интеграции. Основной проект не редактировать.

## Что сделать

1. **RNG.** Найти реализацию `irandom` в EXE/Tcl оригинала (ROADMAP, фаза 5,
   прямо называет `irandom` предметом исследования). Если её нет — сделать
   свой детерминированный RNG по seed и **явно пометить его как адаптер**:
   уровни будут «в духе оригинала», но не те же.
2. **Парсер шаблона.** Разобрать `data/Templates/urw_*.tcl` → структура
   (pmp-путь, l2m-путь, список объектов с локальными координатами, поворотами,
   флагами и атрибутами). Покрыть хотя бы все шаблоны, участвующие в
   `first_level` Urwald.
3. **Композитор.** Наложить PMP-геометрию и L2M-слой по смещению на карту
   уровня, разместить объекты с их флагами. Проверить на `urw_hol_001_a`:
   сетка пещеры, материалы, `Pilz`/`Raupe`/`Stein` на своих местах.
4. **Генератор `first_level`.** Перенести таблицы и порядок выбора из
   `Campaign.tcl` (строки 22–191) — включая `present_side` и наборы букв
   `left_letters`/`right_letters`, выбор `comb`/`conn`/`vodo`, цепочки переходов
   и вудо-шаблонов. На выходе — список `(шаблон, x, y)` + список объектов.
5. **Сцена.** Собрать уровень в Godot: стартовый шаблон с гномами, пещера,
   ресурсы; снять туман в прямоугольнике оригинала; удалить `Wuker`.
6. **Self-test** с golden-значениями: по фиксированному seed — ожидаемый
   список шаблонов и их позиций; детерминизм (один seed → один уровень);
   корректность наложения слоя материалов; наличие гномов на старте.
7. Прогнать полный набор self-test-ов проекта, подготовить unified diff и отчёт.

## Ограничения

- Основной проект не редактировать.
- Факт / инженерный адаптер / неизвестное — раздельно. Если `irandom` не
  воспроизведён — это адаптер, и об этом сказано прямо в отчёте.
- Не выдумывать правило: каждое утверждение о поведении оригинала — со ссылкой
  на строку `Campaign.tcl` или файл шаблона.
- Шаблоны — читать из оригинала, не копировать 874 файла в проект без нужды:
  достаточно данных одного уровня плюс композитор.
- GDScript-предупреждения считаются ошибками: типы явно, неиспользуемые
  параметры с `_`, никаких `Variant` без типа.
- Godot запускать через `Start-Process` + `WaitForExit`, иначе он зависает до `quit()`:
  ```
  $p=Start-Process -FilePath 'C:\Users\frant\OneDrive\Рабочий стол\godot\Godot_v4.7.2-stable_win64_console.exe' `
    -ArgumentList @('--headless','--path',$project,'--script','res://tools/<имя>.gd') `
    -RedirectStandardOutput $log -RedirectStandardError ($log+'.err') -PassThru -NoNewWindow
  if(-not $p.WaitForExit(120000)){Stop-Process -Id $p.Id -Force; 'TIMEOUT'}
  ```
