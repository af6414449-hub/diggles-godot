# Задача агенту: source-first оптимизация walkmap после удара кирки

## Цель

Найти безопасный путь устранения фризов при вскопке terrain в Godot-порте,
сохранив source-derived контракт `native_walkmap.rebuild_after_strike`.

Текущая проблема измерена: после локальной mesh-перестройки основной остаток
задержки создаёт `native_walkmap.rebuild_after_strike`, который пересчитывает
широкий прямоугольник зависимостей. Нельзя решать задачу простым сужением
прямоугольника без доказательства эквивалентности оригиналу.

Это исследование и подготовка интеграции. Основной проект не редактировать.

## Что сделать

1. Разобрать текущую зависимость:
   `terrain_state.apply_accepted_step` → `patch.invalidations` →
   `native_walkmap.rebuild_after_strike` → `terrain_sample_query`.
2. Найти в исходных Tcl/EXE/BDB доказательство области invalidation и того,
   какие samples реально могут меняться после одного ударa. Явно отделить
   доказанные границы от host-оптимизаций.
3. Предложить один или два безопасных варианта:
   - инкрементальный cache / dirty sample set с доказуемой эквивалентностью;
   - двухфазное обновление, где критические samples готовы синхронно, а
     неиспользуемые — позже, с гарантиями для гномов.
4. Для каждого варианта дать оценку сложности, риска рассинхронизации,
   ожидаемой стоимости на карте 128×128 и конкретный API/патч.
5. Подготовить unified diff для изолированных `.gd`/self-test файлов **в своём
   дереве**, но не применяй его к основному проекту.
6. Добавить regression self-test, который сравнивает оптимизированный walkmap
   с текущим полным `rebuild_after_strike` на серии corridor/cave/wall ударов:
   flags, unknown samples, representatives, результат пути и доступность
   забоя должны совпадать.
7. Запустить тесты и приложить результаты. Если эквивалентность не доказана,
   не выдавай оптимизацию как готовую — оформи план нужного RE.

## Ограничения

- Не меняй основной проект.
- Не подменяй native walkmap упрощённой плоскостью или A* только для теста.
- Не считай отсутствие видимого бага доказательством эквивалентности.
- Не делай предположений о поведении оригинала без ссылки на Tcl/EXE/данные.
