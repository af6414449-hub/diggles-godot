# Пробы форматов ресурсов

Дата: 2026-11-14

## Результаты

### `.wav`

Файлы начинаются с `RIFF....WAVE`, то есть это стандартный WAV/RIFF. Их можно читать обычными Android/SDL-аудиосредствами после проверки кодеков и частот дискретизации.

### `.tga`

Первые байты соответствуют заголовку TGA: `00 00 02 00 ...`. Это несжатые true-color изображения. Формат пригоден для раннего импорта без сложного reverse engineering.

### `.hlsl`, `.fx`, `.fxh`

Это текстовые шейдеры/включаемые файлы. Примеры `.hlsl` содержат директивы `#include`, а `.fx` — HLSL-описания ресурсов и стадий. Нельзя рассчитывать на прямой запуск на Android; потребуется трансляция или собственный упрощённый shader backend.

### `.ent`

Непустые файлы содержат простой текстовый формат, например:

```text
map_entry 1 48 0
```

При этом значительная часть файлов имеет нулевой размер. Нужно учитывать пустые маркеры и значения по умолчанию.

### `.l2m`

Непустые файлы начинаются с сигнатуры `M2L\0`. Наблюдаются повторяющиеся значения `04`, `40`, `C0`, что похоже на компактную бинарную маску/сетку или карту высот. Формат небольшой: первые найденные образцы имеют 44 байта.

### `.pmp`

Первые образцы имеют фиксированный размер 110 байт. Начало содержит повторяющиеся байты `04` и `84`, после чего встречаются little-endian значения. Вероятно, это компактное описание свойств/масок, а не крупный контейнер.

### `.tcl`

Файлы являются обычным текстом в кодировке Windows-1252/ASCII-совместимом виде. Многие файлы пустые или содержат только комментарии. Это пока не доказывает, что Tcl содержит основную игровую логику: часть файлов может быть шаблонами или отключёнными сценариями.

## Приоритеты extractor

1. `.ent` — самый дешёвый формат для полного чтения.
2. `.l2m` и `.pmp` — ключевые малые бинарные форматы, вероятно связанные с картами/шаблонами.
3. `.3db` — отдельный формат 3D-моделей; найден заголовок `3DDB 1.0`.
4. `.tga` и `.wav` — использовать готовые стандартные загрузчики.
5. `.tcl` — индексировать и классифицировать по содержимому, не переносить весь Tcl runtime заранее.
6. HLSL/FX — отложить до появления первой сцены.

## Решение контрольной точки

Ресурсный путь выглядит реалистично: часть форматов стандартная, часть имеет устойчивые сигнатуры и малый размер. Следующим техническим артефактом должен стать read-only-инструмент, который строит JSON/CSV-индекс ресурсов и извлекает метаданные без изменения оригинальной установки.
