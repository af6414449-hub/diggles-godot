## Что сделать

1. Сверить обязательные файлы из раздела 2 передаточной инструкции с текущим
   основным проектом. Составить точный список: `copy as-is`, `requires adapter`,
   `already compatible`, `do not copy`.
2. Проверить API текущего `native_tasklist.gd` и подготовить минимальный
   обратносуместимый патч, добавляющий Tcl-имена (`cnt`, `rem`, `list`,
   `pop_front`, `has_pending`) без изменения поведения гномов.
3. Подготовить **unified diff** только для:
   - новых hamster-модулей/данных;
   - `native_tasklist.gd`;
   - минимальных якорных вставок в `multiplayer_test.gd`;
   - новых self-tests.
4. В патче `multiplayer_test.gd` использовать текстовые якоря актуального
   файла, а не номера строк. Не затрагивать текущую систему terrain refresh,
   факелов, выделения, света каски, навигации гномов или world-space.
5. Встроить проверки размещения: четыре хомяка, исходные клипы, два уровня
   пола, отсутствие левитации, поворот до ходьбы, реакция на близкого гнома,
   поиск/исчезновение еды.
6. Запустить доступные headless-тесты в собственном рабочем дереве. Отделить
   реальные результаты от непроверенных предположений.
