## Что это меняет для порта

* **Бит 1 «ступенька» приходит из файла `.pmp`** (RLE-код `v & 3` = 3), если `.pmp` не перебит прогоном «World validate». Порт, который строит откосы по разности высот соседей (З1/З3), **не может воспроизвести исходные уступки без чтения `.pmp`**. Это практическое следствие: нужен ридер RLE-части `.pmp`.
* В оригинале карта суб-клеток — общий буфер с тремя независимыми писателями. Значит воспроизводить надо **не конечное состояние, а порядок операций**: сначала высоты/блоки, затем карта суб-клеток из `.pmp`.
* Если порт будет поддерживать загрузку сохранений, надо учитывать, что «World validate» перезаписывает карту суб-клеток по всей карте.

* **Семантика остальных 12 типов очередей валидатора** — установлено только соответствие «бит флага → номер очереди».
* **Полная формула beautifier'а** (как из высот получается бит 1) — восстановлен порог «+2» (`FUN_005a6b40:120-130, 434-469`), но формула целиком не выписана (`:120-500`).
