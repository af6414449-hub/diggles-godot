
### Решение владельца по семейству текстуры: по кадру оригинала

Вопрос был: семейство текстуры свободной земли — по декомпиляции (группа из
`cell+0x14`, у свободной земли 0 ⇒ группа A, гранит) или по сейву (материал
клетки: 0/3 → A, 1 → B, 2 → C)?

**Решение владельца (22.11.2026): по кадру оригинала.** Проверка по кадру:
земля карты в оригинале — бурая (семейство C), гранит — только на поясе
барьера (семейство A). Правило порта (материал → семейство) даёт ровно это:
по сейву 265 504 клетки земли (код 2) и 59 903 клетки камня (код 0), и код 0
лежит ровно на поясе барьера. Значит действующее правило остаётся, а чтение
«группа A» из `cell+0x14` к свободной земле карты не относится.

Замер по кадру владельца и по моему, один и тот же участок (кадр владельца
1633 px, мой 1280 px, рамка пересчитана по масштабу):

| | северо-запад острова | юго-восток острова |
|---|---|---|
| кадр владельца | (66.4, 58.3, 49.8), R−B = +16.7 | (74.3, 64.3, 54.3), R−B = +20.0 |
| порт | (57.7, 53.8, 47.2), R−B = +10.5 | (72.0, 61.7, 51.1), R−B = +20.9 |

Юго-восток совпадает, северо-запад темнее на 9 единиц. Причина найдена в
сейве: **byte 29 записи клетки карты — уровень света клетки** (256 разных
значений, распределение ровное), а порт выгружает из записи только byte 28
(состояние/материал) и берёт для свободной земли средний атрибут главы.
Свет факелов, запечённый в карту сейва, в порт не попадает — отсюда и
темнота земли у главы.

**Следующий шаг (в моей зоне):** выгрузить byte 29 как карту света карты и
заменить им средний атрибут свободной земли.
