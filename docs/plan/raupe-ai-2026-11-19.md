### Уточнения к формулировкам спецификации

1. **`farmed` → `free`:** спецификация говорит «если ферма невалидна → сразу free». Точнее:
   невалидна ферма **или** её `buildupstate` ложно → `free`.
2. **Условие «точка не найдена» в `crawl_farmed`:** спецификация формулирует «не найдена точка».
   В оригинале порог строгий — `lindex $place 0 < 1` (в `crawl_free` — `< 0`). Это разные
   пороги, в портe надо различать.
3. **Период урона:** 1.2 с между тиками урона (`wait 0.2` + `wait 1`) — верно; но первый
   «замах» длится 0.5/0.9 с плюс пауза 1 с, то есть первый урон приходит позже.
4. **Кулдаун 50 с общий** для `recreate_raupe` и `recreate_hamster` (общая переменная
   `lastcreation`) — хомяк в ферме блокирует пересоздание червя.
5. **Порядок в `crawl_free`:** базовый поворот считается до вызова `find_plant`, но
   блуждание выполняется только если цель не найдена — семантика спецификации верна.

## 2. Чего спецификация правильно НЕ утверждает

- Нет данных о боевом поиске цели-гнома, лазании по стенам, сетевой репликации и
  командах игрока для червя.
- `aggr_events.tcl` подключается классом, но вызова `check_for_player_contact` нет —
  червя нельзя делать враждебным юнитом.
- `Raupe` — это фермерское едовое существо, а не монстр; отдельный модуль от хомяка.

4. `tools/native_raupe_scene_self_test.gd` — headless-сцена: загрузка без ошибок,

5. Модели и клипы `raupeNN` — только после инвентаризации исходных ассетов; до этого
   переходы состояний должны быть полными без геометрии.

### Обязательные проверки

- 13 вариантов выбираются; ровно `02/06/07/08` никогда не входят в `plant_attack`.
- Свободный актор при видимости < 10 не выдаёт навигационный запрос; неудачный
  `get_place` → ожидание 3 с.
- Классификация фермы и освобождение — по 1-секундному таймеру; contained ждёт по 4 с.
- Хищный актор: поиск растения на 11-м тике, подход до `0.55 ± 0.1`, урон и самоурон
  только после замаха, смерть при HP < 0.01.
- Исчезновение растения, невалидная ферма, переход через инвентарь и снятие lock
  не оставляют протухшей цели или лока.
- Повтор с тем же seed даёт идентичную последовательность переходов и точек.
- Правила фермы: максимум 6, порог `60 - material*12 + rand()*5`, корм 30, кулдаун 50 с,
  прямоугольник x ±1.7 / z ±2.5.

## 6. Поправки сверки от 2026-11-19 (при реализации)

1. **`attacktyp` — инверсия.** Оригинал `raupe.tcl:48-52`:
   `if {[land $rtyp {02 06 07 08}]==""} {set attacktyp 0} else {set attacktyp 1}`.
   `land` ищет элемент по списку (подтверждено 30 вызовами в игре), значит
   `attacktyp = 1` получают типы **02, 06, 07, 08** — хищных четыре, а не девять.
   `find_plant` выходит при `attacktyp == 0` (`:119`), то есть искать растение
   могут только эти четыре.
2. **Порядок в `crawl_free`.** Гейт `get_max_fow < 10` (`:68`) стоит **до**
   `find_plant` (`:72`): при недостаточной видимости червяк не блуждает и не
   ищет растение. В спецификации порядок был переставлен.
3. **Прямоугольник фермы** всегда `x -2..1.5`, `z -3..3` относительно фермы,
   даже когда центр — гном (`:98-108`).
4. **Инициализация фермы:** `farmcounter` = 50 (`farm.tcl:74`), `wormfodder` = 100
   для ветки Raupe (`:79`), `lastcreation` = 0.0 (`:140`).
5. **Счётчик фермы** растёт только когда гном был, порог не пересечён и в ферме
   есть черви (`:248-259`).
