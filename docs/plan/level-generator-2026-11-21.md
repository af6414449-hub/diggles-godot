# Блок «Генератор уровня оригинала» — 21.11.2026

Отдельный блок, сделанный в SideChat, чтобы не пересекаться с Main Chat (порода,
гранит, свет главы) и с основным чатом (грунт, освещение, геометрия поверхности).

Отчёт: `docs/reverse-engineering/agent-result-level-generator-2026-11-21.md`.

## Что сделано

| Файл | Что это |
|---|---|
| `tools/build_level_template_inventory.py` | инвентарь шаблонов генератора из установленной игры → `godot/models/native_level_templates.json` (301 КБ): имена, размеры, объекты, **точки соединения** |
| `godot/scripts/native_level_generator.gd` | генератор уровня: сетка 4, зона отступа 4, бюджет заполнения, цепочка по точкам соединения, оценка шаблона |
| `godot/tools/native_level_generator_self_test.gd` | 98 проверок против фактов оригинала и против правил натива |
| `godot/tools/native_level_generator_dump.gd` | дамп плана уровня в JSON |
| `tools/export_generated_level.py` | выгрузка плана в формат главы (переиспользует экспортёр главы) |
| `godot/scripts/native_generated_level_preview.gd` + `godot/scenes/generated_level_preview.tscn` | превью сгенерированного уровня |
| `godot/models/native_generated_level*.json` | данные сгенерированного уровня (Urwald, seed 12345, участок 300×0 160×96) |

## Факты оригинала, которые закрыты

* группы шаблонов генератора по четырём мирам и их реальный состав
  (`lginit.tcl:8-43`): Urwald 143 туннеля / 9 концов / 40 пещер;
* классы фильтра (`lginit.tcl:6`) — девять, включая уголь, золото, железо,
  кристалльную руду и сундук;
* нормы ресурсов по зонам (`story.tcl:960-987`): **в Urwald руды нет, только
  12 грибов**;
* доля пещер в зоне (`story.tcl:142-146`): Urwald 0.287;
* синтаксис группы и свойства шаблонов (`lgtools.tcl:4-56`, `lginit.tcl:46-51`),
  включая `-levelcount 1` для каждого шаблона групп `.hol` и `.gsg`;
* **точки соединения шаблонов** — `data/Templates/<набор>.ent`, тот же разбор,
  что в нативе (`FUN_005826d0`): вид точки 1, сторона выводится из её места;
  проверено на всех 645 шаблонах;
* **нативный алгоритм `lg_start`** — восстановлен из декомпиляции Diggles.exe:
  позиции кратны 4, зона отступа 4 клетки на сторонах без точки соединения,
  блок не накладывается на зону другого шаблона, уровень наполняется до доли
  площади участка, шаблон выбирается оценкой, цепочка растёт от открытых концов.

## Проверка

* `native_level_generator_self_test` — 98/98;
* полный набор проекта — без падений (результат в ответе сессии и в
  `out/agent-levelgen-2026-11-21/suite/`).

## Не сделано

* условие остановки натива (доля `optratio` против предела `ratio`) — в порте
  уровень останавливается по достижении доли, это адаптер;
* проверка открытого конца в `FUN_00584120` — в декомпиляте противоречит
  разметке блока, сведена к проверке зоны отступа;
* прямоугольник группы (`FUN_00587480`), куда натив ставит пещеру и галерею,
  не восстановлен — пещера копается рядом с цепочкой;
* прямоугольники участков зоны (`sm_get_level_info`) — это данные движка, в порте
  участок задаётся параметром;
* свободный грунт и тело породы вокруг сгенерированного уровня — план породы
  главы (воронка из сейва) принадлежит сцене главы, блок не трогает.
