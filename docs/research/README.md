# Research-документы: индекс и порядок изучения

Каталог 14 файлов, собранных из присланных материалов. Это **внешняя реконструкция по публичным источникам** (Wikia/Steam-гайды, разборы сообщества, каталоги видео, отчёты о моддинге), а не выжимка из установленной игры.

## Правило использования

- Шкала уверенности, как в самих документах: **D** — прямо документировано в источнике; **R** — реконструировано из нескольких свидетельств; **I** — интерпретация автора документа; **U** — неизвестно / вопрос открыт.
- Любое утверждение отсюда — **гипотеза**, пока не сверено с оригиналом (`C:\Program Files (x86)\Steam\steamapps\common\Diggles The Myth of Fenris\data`, только чтение) или с записью в игре.
- Числа из этих файлов нельзя тащить в код как константы. В отчёте по каждому шагу помечай: факт / инженерный адаптер / неизвестное.

## Что изучать сейчас

Порядок совпадает с планом проекта (`docs/plan/queue-2026-11-19.md`, §0.8).

1. **Шаг B — гном как самостоятельный агент.** Читать: `diggles_life_simulation.md`, разделы «Поведение гномов» и «Инвентарь» из `diggles_research.md`, раздел «Worker rules» из `diggles_economy_research.md`, разделы 2.2–2.3 из `Diggles_Combat_AI_Research.md`.
2. **Шаг C — фермы и предметы.** Читать: `diggles_economy_research.md` (ресурсный граф, цепочки, матрица зданий), `diggles_technology_tree.md`.
3. **Шаг E — диалоги и сюжет.** Читать: раздел про `new`/объекты и шаблоны в `diggles_public_reverse_engineering.md`, `diggles_localization_research.md` (формат строк).
4. **Шаг D — бой (M6).** Читать: `Diggles_Combat_AI_Research.md` целиком, раздел «Существа» из `diggles_research.md`.
5. **Шаг F — Android.** Читать: `diggles_render_performance_research.md` (бюджеты и профилирование), `Diggles_UX_Control_Research.md` (жесты), `diggles_localization_research.md`.

## Что отложить

- `diggles_multiplayer_research.md` — сетевой режим не входит в план A–F; вернуться, если будет отдельная задача.
- `diggles_render_performance_research.md` — до шага F; часть разделов описывает модов, а не оригинал.
- `Diggles_audio_spec.md`, `diggles_visual_spec.md` — нужны, когда появится движок сцены; сейчас полезны только как список подсистем.
- `diggles_skirmish_research.md` — режим сражения; кампания и сражение в оригинале используют разные данные, смешивать нельзя.

## Как проверять

- Tcl оригинала: `data/Scripts/gameplay/Campaign.tcl` (карта кампании), `data/Scripts/` (общие скрипты), `data/Templates/` (шаблоны карт и объектов).
- Данные: `data/3db/`, `data/Ground/`, `data/Texture/`, `data/3DB` — всё только чтение.
- Уже извлечено в проект: `godot/models/native_campaign_chapter.json` (сборка главы кампании), `godot/models/native_campaign_models.json` (объекты главы), `godot/models/native_terrain_render.json` (правила текстур земли), `godot/models/native_world_model_lighting.json` (свет).
- Если утверждение из research нельзя подтвердить источником — оно остаётся в статусе «I» и не идёт в код как факт.
